# The AI-First BFSI Company — A North Star Operating Model

An interactive, single-page model of what a large Indian NBFC looks like when AI agents do
the work — across the full customer lifecycle and every enterprise support function, with
human judgment placed deliberately rather than decoratively.

Built for a leadership audience, and built to survive the objection that usually kills these
discussions: *"the regulator will never allow it."*

## The two ideas doing the heavy lifting

**Autonomy is a per-decision setting, not a company setting.** Five levels, from *human decides
/ AI informs* to *fully autonomous / exception-only human*. Autonomy is granted against evidence
— evaluations, incident rates, audit findings — and revoked automatically when that evidence
decays. This reframes "should AI do this?" into a question a board can actually adjudicate.

**Generative models never make regulated decisions.** LLM agents gather, structure, explain,
draft and converse. Credit, pricing, fraud classification and financial reporting run on
governed, versioned, independently validated deterministic engines. That single boundary is
what makes the rest of the architecture defensible.

Where regulation specifies *who* performs an act, the human stays: video KYC concluded by an
authorised officer, suspicious transaction reporting by the Principal Officer, financial
statements signed by the CFO, and no adverse employment action taken on an AI output alone.

## Running it

No build step, no dependencies, no network calls. Clone and open `index.html` in any modern
browser, or view the hosted page above. Light and dark themes both supported.

```
git clone https://github.com/nitinbandgar/ai-first-bfsi-north-star.git
```

## Disclaimer

This is an **independent, illustrative concept model of a generic diversified Indian lender.**
It is not affiliated with, endorsed by, or descriptive of any specific company, and it
represents no organisation's plans or commitments.

All metrics shown are **directional benchmarks for discussion, not measured results.**

Regulatory references — covering RBI digital lending, KYC and V-CIP, fair practices and
recovery conduct, IT governance and outsourcing directions, along with DPDP 2023, PMLA,
CERT-In directions and SEBI/IRDAI distribution boundaries — are **indicative and stated as at
the time of writing.** Regulation changes. Nothing here is legal, compliance or investment
advice. Validate every reference against current source texts with qualified counsel before
acting on any of it.
